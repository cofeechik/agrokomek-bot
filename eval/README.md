# Оценка

`node scripts/fetch-samples.js` скачивает 9 реальных фото в игнорируемый каталог `eval/private` и создаёт manifest.json. `npm run eval -- eval/private/manifest.json` запускает реальные запросы к API и расходует квоту. Результаты сохраняются в `results.local.json`, автоматически не публикуются.

Это детерминированная небольшая выборка для технической проверки. До убедительной оценки качества нужны дополнительные реальные полевые фотографии, независимая разметка, одинаковый сценарий для всех примеров и достаточно примеров каждого класса. Не меняйте промпт по результатам и затем не называйте тот же набор независимым тестом.
