# Сценарий демонстрации, 2–3 минуты

0:00–0:20. «AgroKomek помогает разобраться, что проверить, когда на листьях появились изменения. Начинаем с картофеля. Это предварительный осмотр по фото, не лабораторный диагноз».

0:20–0:40. Открыть бота, `/start`, показать выбор языка и пять региональных культур. Объяснить передачу фото для анализа.

0:40–1:20. Отправить реальное фото с правом использования. Для PlantVillage указать автора/датасет и лицензию в подписи видео. Показать сообщение ожидания, признаки, предположение и действия. Не монтировать ожидание так, будто анализ мгновенный; ускорение подписывать.

1:20–1:50. Нажать «📈 Наблюдение», отправить более ранний и новый снимки. Показать сравнение видимых изменений и объяснить, что фото хранятся только в памяти на время сценария.

1:20–1:45. Показать нерелевантное изображение или нечёткое фото: система должна отказаться от уверенного вывода. Переключить язык.

1:45–2:10. Показать последний результат и кратко объяснить, почему нет процентов уверенности и назначения препаратов.

2:10–2:40. Назвать только фактические метрики из завершённого прогона. Отдельно отметить маленькую лабораторную выборку и отсутствие полевых испытаний. Показать открытый репозиторий.

Перед записью: проверить ключи, лимиты, доступность сервера; не показывать `.env`. Для Demo Day подготовить резервное видео на случай отсутствия интернета.
