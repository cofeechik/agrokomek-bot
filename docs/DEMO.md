# Сценарий демонстрации, 2–3 минуты

0:00–0:25. Начать с целевой аудитории: работники хозяйств и фермеры, которым нужна помощь при первичном осмотре. Вступление и проверенные данные с датами — в `PITCH_INTRO.md`.

0:25–0:40. Открыть бота, `/start`, показать выбор языка, пять региональных культур и «Другое растение».

0:40–1:20. Отправить реальное фото с правом использования. Для PlantVillage указать автора/датасет и лицензию в подписи видео. Показать сообщение ожидания, признаки, предположение и действия. Не монтировать ожидание так, будто анализ мгновенный; ускорение подписывать.

1:20–1:50. При подключённой истории нажать «📈 Наблюдение», выбрать ранее сохранённый осмотр по дате и фото и отправить один новый снимок. Показать сравнение и «📊 Сводка». Если снимки сделаны сегодня, не выдавать демонстрацию за неделю реального наблюдения.

1:50–2:10. Показать пример неопределённого результата. Объяснить, что сводка описывает снимки пользователя, а полевые испытания ещё предстоят.


2:10–2:40. Назвать только фактические метрики из завершённого прогона. Отдельно отметить маленькую лабораторную выборку и отсутствие полевых испытаний. Показать открытый репозиторий.

Перед записью: проверить ключи, лимиты, доступность сервера; не показывать `.env`. Для Demo Day подготовить резервное видео на случай отсутствия интернета.
