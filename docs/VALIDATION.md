## Программные тесты

Автоматизированные проверки включают проверку и сжатие файлов, отказ от определённого диагноза при неопределённости, экранирование текста, схему Gemini, лимиты, первое уведомление о передаче фото, устранение повторов, ошибки квот и авторизацию webhook. Выполняются командой `npm test`, без реальных ключей.

Повторная проверка 21 сентября 2026 года: **20 из 20** тестов прошли, включая локализованную карточку «Сигнал агроному» и сценарий сравнения снимков. `npm audit --omit=dev` сообщил о 0 известных уязвимостях. Публичный `/healthz` на Render вернул HTTP 200; после пробуждения прогретый экземпляр ответил за 0,87 секунды.

Повторный прогон на 9 фотографиях 21 сентября не завершён: Gemini вернул шесть ответов HTTP 503 и один HTTP 429. Эти запросы не использованы для пересчёта качества. Инцидент показывает зависимость MVP от внешнего API и необходимость резервного видео для демонстрации.

## Не завершено

- Независимая полевая оценка с агрономом и более крупной выборкой.
- Полная проверка пользователем внутри Telegram на своём телефоне.
- Стабильный замер холодного старта Render отдельной серией запросов.
- Проверка казахского текста носителем языка.
- Подтверждение экономического эффекта.
